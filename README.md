# QAZAQ POP-UP — мобильді қосымша (PWA)

## Ішінде не бар
- `index.html` — қосымшаның өзі
- `manifest.json` — қосымша атауы, белгішесі, түстері
- `sw.js` — офлайн режим (интернетсіз ашылу)
- `icons/` — белгішелер

## 1. Интернетке шығару (тегін, 5 минут)
Телефонға орнату үшін қосымша **https** сілтемемен ашылуы керек.

**Netlify Drop (ең оңайы):** app.netlify.com/drop сайтына кіріп, осы папканы (zip-ті ашқаннан кейін) терезеге сүйреп таста. Сілтеме бірден беріледі.

**GitHub Pages:** жаңа репозиторий аш → барлық файлдарды жүкте → Settings → Pages → Branch: main → Save. Сілтеме: `https://<атың>.github.io/<репозиторий>/`

## 2. Телефонға орнату
- **Android (Chrome):** сілтемені аш → қосымшадағы «Орнату» батырмасын бас (немесе ⋮ мәзір → «Қолданбаны орнату»).
- **iPhone (Safari):** сілтемені аш → «Бөлісу» ⬆️ → «Басты экранға қосу».

Белгіше басты экранға шығады, қосымша толық экранда ашылады және интернетсіз де жұмыс істейді (Google Maps-тан басқасы).

## 3. Play Market-ке арналған APK / AAB (қаласаң)
Сайт интернетте тұрғанда pwabuilder.com сайтына сілтемені қойып, «Package for stores» → Android таңда. Ол дайын Android пакетін жасап береді.

## Жаңарту
`index.html`-ді өзгерткен сайын `sw.js` ішіндегі `qazaq-popup-v4` атауын `v5`, `v6`... деп өзгерт — сонда телефондар жаңа нұсқаны жүктейді.

## QR арқылы орнату (install.html)
QR-код `.../install.html` бетін ашады. Бет телефонды өзі таниды:
- **Android:** `qazaq-popup.apk` файлы папкада болса — «APK жүктеп, орнату» батырмасы шығады; болмаса — «Қосымшаны орнату» (PWA) батырмасы.
- **iPhone:** «Басты экранға қосу» нұсқауы шығады.

**APK қосу:** PWABuilder-ден алған `.apk` файлын `qazaq-popup.apk` деп атын өзгертіп, осы папкаға (index.html жанына) салыңыз да, Netlify-ға қайта жүктеңіз. Басқа ештеңе өзгертудің қажеті жоқ.
